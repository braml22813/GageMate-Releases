# Security policy

Please **do not publicly disclose security vulnerabilities through GitHub Issues**.

Report suspected security issues privately to sales@arcpathautomation.com with the subject line `GageMate Security Report`. Include the affected version, a description of the issue, and reproduction details. Do not include sensitive customer data.

The publisher will review reports and determine appropriate remediation. No formal response or patch timeline is guaranteed.

Only obtain installers from the official GitHub Releases page or another distribution location explicitly identified by ArcPath Automation & Design LLC.
