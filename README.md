# GageMate

**Free statistical analysis and manufacturing quality software for Windows**  
Developed by **ArcPath Automation & Design LLC**.

GageMate is a desktop application for manufacturing engineers, quality professionals, and technicians who need practical tools for measurement system analysis (MSA), statistical process control (SPC), and data analysis.

## Download

**[View the latest GageMate release](../../releases/latest)**

Download `GageMate_Setup_1.3.0.exe` from the release assets for version 1.3.0. For newer releases, select the installer matching the published version.

GageMate is currently distributed as a Windows installer. No separate Python installation is required for the packaged application.

Windows 11 is the only OS tested and officially supported. This does require an executable install, which may be limited on Company IT issued PCs.

> Download installers only from the official release page. Verify the publisher and any provided SHA-256 checksum before running the installer.

## Features

- **Measurement System Analysis:** Type 1 Gage R&R, ANOVA Gage R&R (including crossed, nested, and expanded study options), and Attribute MSA.
- **Statistical Process Control:** Individuals–Moving Range (I-MR) and Xbar-R control charts.
- **Distribution and normality:** Histograms, normality tests, probability plots, and descriptive distribution views.
- **Capability and performance:** Process capability/performance analysis with specification limits, where supported by the installed version.
- **Additional analysis:** Basic statistics and curve fitting.
- **Reports and charts:** Interactive Plotly charts and report export options.
- **CSV workflow:** Import measurement data from CSV files for analysis.

Available options and calculations may vary by release. Review the release notes for changes.

## Getting started

1. Open the [Releases](../../releases) page.
2. Download the installer asset for the version you want.
3. Verify the checksum if a `SHA256SUMS.txt` file is provided.
4. Run the installer and review the EULA and third-party notices.
5. Launch GageMate, import a CSV dataset, and select an analysis.

See [Installation](INSTALLATION.md) for troubleshooting and setup guidance.
