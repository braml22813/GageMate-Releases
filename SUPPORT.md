# Support and feedback

Use [GitHub Issues](../../issues) for reproducible bugs, installation problems, and feature requests.

For a useful bug report, include:

1. GageMate version (for example, 1.3.0).
2. Windows edition and version.
3. Analysis module and configuration used.
4. Steps to reproduce the issue.
5. Expected behavior and actual behavior.
6. Error messages or screenshots, if available.

**Privacy:** Do not publish customer data, confidential measurement results, internal part numbers, personal information, or proprietary files. Use a small synthetic CSV sample when possible.

For other inquiries, contact sales@arcpathautomation.com.

This repository distributes releases and documentation; it does not contain the private application source code.
